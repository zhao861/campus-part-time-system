# 校园兼职系统

#### Description
技术栈：Vue3 + Element Plus + SpringBoot3 + MyBatis + MySQL + RESTful API 
项目描述：采用前后端分离架构开发校园兼职管理系统，覆盖多角色（学生/商家/管理员）
的兼职全流程管理，核心解决校园兼职信息分散、管理效率低的问题。
